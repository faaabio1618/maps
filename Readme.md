# Beautiful Maps

Beautiful Maps is a small Python library for generating attractive map images and visualizations with a simple API.

## Features

- Easy map generation from GeoJSON or coordinate lists
- Layered styling and color palettes
- Export to PNG and SVG
- Lightweight and pip-installable

## Requirements

- Python 3.8+
- `pip`
- See `requirements.txt` for exact dependencies

## Installation

```bash
git clone https://github.com/faaabio1618/beautiful-maps.git
cd beautiful-maps
python -m venv venv
venv\Scripts\activate
pip install -r `requirements.txt`

```
